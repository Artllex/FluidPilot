# FluidPilot

## Short description

Fluid Player controls, adjustable loops, timeline preview, and GIF and WebM export.

## Full description

FluidPilot improves websites that use a compatible Fluid Player layout. It adds reliable playback controls, precise seeking, an adjustable loop with a clear indicator, frame preview on the timeline, and export of the active loop as a GIF or WebM recording.

The optional 5% volume mode can be toggled with a shortcut and is saved across Firefox tabs and sessions.

The extension activates automatically when it detects a supported player. It does not collect or transmit user data.

## Permission rationale

- **Website access:** required to detect embedded Fluid Player instances and add controls.
- **Extension storage:** used only to retain the global 5% volume preference.
